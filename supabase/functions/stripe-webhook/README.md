Supabase Edge Function — stripe-webhook

Overview
- This Edge Function verifies Stripe webhook signatures, updates the `orders` table using the Supabase service role key, and sends transactional emails via SendGrid.

Files
- `index.ts` — main Edge Function handler

Required database (run in Supabase SQL editor)
```sql
CREATE TABLE public.orders (
  id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  order_id text NOT NULL,
  customer_name text NOT NULL,
  customer_email text NOT NULL,
  phone_number text,
  delivery_address text,
  product_name text NOT NULL,
  product_handle text,
  shoe_size text,
  amount_minor int4 NOT NULL,
  currency text NOT NULL,
  order_status text NOT NULL DEFAULT 'pending',
  payment_status text NOT NULL DEFAULT 'pending',
  stripe_checkout_session_id text,
  stripe_payment_intent_id text,
  paid_at timestamptz,
  payload jsonb,
  created_at timestamptz DEFAULT now(),
  updated_at timestamptz DEFAULT now()
);
CREATE UNIQUE INDEX ON public.orders (order_id);
```

Environment / secrets
- Use `supabase secrets set` (or platform secrets) to provide:
  - `SUPABASE_URL`
  - `SUPABASE_SERVICE_ROLE_KEY` (service role key — keep secret)
  - `STRIPE_WEBHOOK_SECRET` (from Stripe webhook settings)
  - `SENDGRID_API_KEY` (or set `SMTP_*` and adapt the function)
  - `ADMIN_EMAIL`
  - `SITE_URL` (optional)
  - `SUPABASE_ORDERS_TABLE` (if you use a different name)

Deploying the function (with Supabase CLI)
1. Install and login to Supabase CLI: https://supabase.com/docs/guides/cli
2. From repo root, run:
```bash
supabase functions deploy stripe-webhook --project-ref your-project-ref
```
3. After deploy, obtain the function URL from the CLI output or Supabase dashboard.

Configuring Stripe webhook
1. In Stripe Dashboard → Developers → Webhooks → Add endpoint
2. Set the endpoint URL to your function URL: `https://<project>.functions.supabase.co/stripe-webhook`
3. Subscribe to event `checkout.session.completed` (and optionally `payment_intent.succeeded`)
4. Stripe will provide a signing secret — set that as `STRIPE_WEBHOOK_SECRET` in Supabase secrets

Testing locally
- For local testing use `supabase functions serve` (requires CLI) and expose with `ngrok` or `cloudflared` so Stripe can reach it.
- Or use Stripe Dashboard's "Send test webhook" targeting the deployed function URL.

Notes
- This function uses the Web Crypto API to validate Stripe signatures (no Stripe SDK required). It sends email via SendGrid — if you prefer SMTP, replace `sendEmailSendGrid` with an SMTP call (adapt for Deno).
- Keep `SUPABASE_SERVICE_ROLE_KEY` secret and never expose it to client-side code.
